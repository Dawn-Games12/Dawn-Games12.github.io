プライバシーポリシー

制定日：2026年10月18日　改定日：2026年10月19日（広告について追記）

Dawn Games（以下「私たち」）は、スマートフォン向けゲーム『夜明けの残響』（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 私たちのサーバーには、何も送られません

本アプリは、私たちが運営するサーバーを使いません。利用者がゲーム内で入力した言葉や設定が、私たちに送られたり、私たちのもとに保存されたりすることはありません。ただし、下の「発言の報告」を利用者が自分で送った場合に限り、その報告の内容が私たちに届きます。

発言の報告

チャットの友人の吹き出しを長押しすると、AIが作った不適切な発言を私たちに報告できます。報告を送ったときに限り、次の内容が Google フォーム（Google LLC のサービス）を通じて私たちに届きます。

  • 報告した発言の文章
  • 誰の発言か（友人の名前）、使っていたAIのモデル名、アプリのバージョン
  • 選んだ理由

利用者の名前や、そのほかの会話の内容は送られません。報告は、AIへの指示を改善し、不適切な発言を減らすためだけに使います。

2. 入力した言葉の送り先（Google の Gemini API）

本アプリでは、友人たちの返事をAIが作ります。そのため、利用者がゲーム中に入力した言葉と、その夜のチャットの内容は、利用者自身が登録したAPIキー（合鍵）を使って、Google LLC の Gemini API に直接送信されます。

  • 送信された内容の取り扱いは、Google の利用規約とプライバシーポリシーに従います。
  • Gemini API の無料枠では、送信された内容が Google のサービスの改善に使われることがあります。本名、住所、電話番号などの個人情報は入力しないでください。

参考：Gemini API 追加利用規約／Google プライバシーポリシー

3. 端末の中だけに保存する情報

次の情報は、利用者の端末の中だけに保存されます。私たちを含め、外部に送信されることはありません（APIキーは、上記2の送信のときだけ Google に渡されます）。

情報用途
名前友人たちからの呼びかけ
APIキー（合鍵）と、有料のAPIを使っているかどうかの設定Gemini API の利用
クリア回数と戦績、音・文字の設定記録と表示
その日に使ったAIの回数1日に遊べる回数の表示
中断中の夜の内容「つづきから」での再開。夜が終わると消えます

夜が終わると、その夜のチャットの内容は残りません。アプリを削除すると、端末に保存された情報もすべて消えます。

4. 広告

本アプリは、Google LLC の広告配信サービス「Google AdMob」を使って広告を表示します（結果画面と設定画面のバナー、夜が終わったあとの広告、電池を充電するときに利用者が自分で選んで見る広告）。

  • 広告の配信と効果の測定のため、AdMob は、端末の広告ID、IPアドレス、端末とアプリの情報、広告の表示や操作の記録などを収集することがあります。これらは私たちではなく Google が受け取り、Google のポリシーに従って扱われます。
  • チャットの内容、名前、APIキーが広告のために送られることはありません。
  • 地域によっては、最初に広告の同意の確認画面が表示されます。利用者の興味にあわせた広告（パーソナライズ広告）は、端末の設定（Android の「設定 › プライバシー › 広告」など）で広告IDを削除・リセットして止めることができます。

参考：Google のパートナーのサイトやアプリでのデータの使用／Google の広告

5. 対象年齢

本アプリは事故や死を扱う物語を含むゲームで、13歳未満の方を対象としていません。13歳未満の方の情報を意図的に収集することはありません。
