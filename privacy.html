夜明けの証明

プライバシーポリシー

制定日：2026年10月12日

Dawn Games（以下「私たち」）は、スマートフォン向けゲーム『夜明けの証明』（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 私たちのサーバーには、何も送られません

本アプリは、私たちが運営するサーバーを使いません。利用者がゲーム内で入力した言葉や設定が、私たちに送られたり、私たちのもとに保存されたりすることはありません。

2. 入力した言葉の送り先（Google の Gemini API）

本アプリでは、仲間ともう一人の自分の返事をAIが作ります。そのため、利用者がゲーム中に入力した言葉と、その夜のチャットの内容は、利用者自身が登録したAPIキー（合鍵）を使って、Google LLC の Gemini API に直接送信されます。

  • 送信された内容の取り扱いは、Google の利用規約とプライバシーポリシーに従います。
  • Gemini API の無料枠では、送信された内容が Google のサービスの改善に使われることがあります。本名、住所、電話番号などの個人情報は入力しないでください。

参考：Gemini API 追加利用規約／Google プライバシーポリシー

3. 端末の中だけに保存する情報

次の情報は、利用者の端末の中だけに保存されます。私たちを含め、外部に送信されることはありません（APIキーは、上記2の送信のときだけ Google に渡されます）。

情報用途
プレイヤー名・一人称仲間からの呼びかけなど
性格診断の結果もう一人の自分の振る舞いの土台
APIキー（合鍵）Gemini API の利用
クリア回数、音・文字の設定記録と表示
その日に使ったAIの回数1日に遊べる回数の表示
中断中の夜の内容「続きから」での再開。夜が明けると消えます

夜が明けて答え合わせを閉じると、その夜のチャットの内容は残りません。アプリを削除すると、端末に保存された情報もすべて消えます。

4. 広告（Google AdMob）

本アプリは、Google LLC が提供する広告サービス「Google AdMob」を利用しています。AdMob は、広告の配信、効果の測定、不正の防止のために、次のような情報を自動的に収集することがあります。

  • 広告ID（Android の広告ID）
  • 端末の種類、OS のバージョン、おおよその位置（IPアドレスから推定）
  • 広告の表示やタップなどの操作の記録

これらの情報は Google により収集・利用され、私たちが個人を特定できる形で受け取ることはありません。欧州経済領域（EEA）や英国など、法律で求められる地域では、広告の配信前に同意の確認を表示します。広告のパーソナライズは、端末の設定（Google の設定 → 広告）から無効にできます。

詳しくは Google のパートナーのサイトやアプリでのデータ使用／Google プライバシーポリシー をご覧ください。

5. 対象年齢

本アプリはホラー要素を含むゲームで、13歳未満の方を対象としていません。13歳未満の方の情報を意図的に収集することはありません。

6. このポリシーの変更

本アプリの機能の変更などにあわせて、このポリシーを改めることがあります。大きな変更がある場合は、このページでお知らせします。
